## פריסה ב-GitHub Pages

הקובץ `index.html` הוא קובץ עצמאי לחלוטין — אין צורך בשרת או build process.

### צעדים לפריסה:

1. **יצירת ריפוזיטורי חדש ב-GitHub:**
   - לך ל-[github.com/new](https://github.com/new)
   - שם: `obstetrics_calculator` (או כל שם אחר)
   - public/private — לבחירתך
   - אל תוסיף README/license (קיימים כבר)

2. **העלאת הקבצים:**
   ```bash
   cd github-repo
   git init
   git add .
   git commit -m "Initial commit — Obstetric Calculator v3.0"
   git branch -M main
   git remote add origin https://github.com/USERNAME/obstetrics_calculator.git
   git push -u origin main
   ```

3. **הפעלת GitHub Pages:**
   - בריפוזיטורי → Settings → Pages
   - Source: `Deploy from a branch`
   - Branch: `main`, Folder: `/ (root)`
   - שמור — האפליקציה תהיה זמינה תוך כדקה ב-`https://USERNAME.github.io/obstetrics_calculator/`

4. **עדכון הלינק** ב-README בשורה הראשונה — להחליף `YOUR-USERNAME` בשם המשתמש שלך.
